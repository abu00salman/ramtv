# RaM tv

مشغّل IPTV أصلي لآيفون (SwiftUI) بتصميم قريب من Apple TV. مشغّل فقط، لا يتضمن أي قنوات أو محتوى.

## الميزات
- مصادر M3U وXtream Codes (كلمة المرور في Keychain)
- الرئيسية (غلاف كبير + صفوف)، مباشر، المكتبة (أفلام ومسلسلات + حلقات)، بحث، مفضلة، متابعة المشاهدة
- مشغّل AVPlayer: صورة داخل صورة + AirPlay
- عربي (RTL) وإنجليزي، وضع داكن

## بناء ملف IPA بدون حساب مطوّر
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد (الفرع main).
2. افتح تبويب Actions وانتظر انتهاء "Build unsigned IPA" (حوالي 5-10 دقائق).
3. حمّل `RaM-tv-unsigned.ipa` من Releases أو من Artifacts.
4. ثبّته بـ Sideloadly أو AltStore/SideStore بحساب Apple ID مجاني (ينتهي توقيعه بعد 7 أيام ويحتاج إعادة تثبيت).

## عند الحصول على حساب مطوّر
أضف أسرار التوقيع إلى GitHub وغيّر خطوة البناء إلى archive موقّع، ثم ارفع إلى TestFlight.
