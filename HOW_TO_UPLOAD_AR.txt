تحديث RaM TV

1. فك ضغط الملف على جهازك. لا ترفع ZIP نفسه إلى المستودع؛ GitHub لا يفك ضغطه تلقائيًا.
2. افتح مستودع abu00salman/ramtv فقط، وأنشئ فرع development/android-tv-stability من main.
3. من Add file ثم Upload files ارفع محتويات المجلد المفكوك إلى جذر المستودع، مع الحفاظ على المسارات واستبدال الملفات المطابقة. لا تحذف ملفات أخرى.
4. يجب رفع .github/workflows/build-ipa.yml أيضًا. لإظهار المجلدات المخفية في Finder اضغط Command + Shift + نقطة. يمكنك استبدال ملف workflow يدويًا من محرر GitHub إذا لم يقبل رفع المجلد المخفي.
5. انتظر نجاح Actions: quality وAndroid وiPhone وWindows وmacOS. لا تدمج إذا فشل أي بناء.
6. أنشئ Pull Request إلى main وراجع التغييرات. بعد نجاح الاختبارات والمراجعة، دمج الفرع يشغّل البناء مرة أخرى ويُنشئ Release جديدًا تلقائيًا عند نجاح جميع الوظائف.
7. افتح Releases وحمّل ملفات الإصدارات الجديدة. أثناء اختبار الفرع تستطيع تنزيل Artifacts من Actions.

هذه حزمة مصدر كاملة محدثة وليست ملفات تشغيل جاهزة لجميع الأنظمة. تم بناء Android محليًا فقط؛ بناء الأنظمة الأخرى يتم عبر Actions. بيانات التوقيع الحالية وأسماء الأسرار ومسارات استخدامها محفوظة. لا يحتوي ZIP على مفاتيح التوقيع أو ملفات البيئة أو أدوات البناء المحلية.
